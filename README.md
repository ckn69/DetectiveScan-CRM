# DetectiveScan · Plateforme

Plateforme SaaS B2B pour les hôtels : espace hôtelier, back-office DetectiveScan et expérience joueur (QR codes en chambre).

## Statut

Cadrage v1.2 (réponses intégrées : essai d'un mois puis 50 € par hôtel via Stripe, site du jeu en HTML branché par un script, QR enregistrés à la main ou par CSV, module Onboarding clients). Aucun code applicatif pour l'instant.

- Dossier de cadrage : [`docs/cadrage/index.html`](docs/cadrage/index.html) (à ouvrir dans un navigateur)
